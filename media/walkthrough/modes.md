# Ask, Plan and Auto

Press **⇧Tab** in the message box to switch modes.

| Mode | What the agent may do |
| --- | --- |
| **Ask** | Read and answer. It can't edit files. |
| **Plan** | Investigate and write a plan for you to review, then build it when you approve. |
| **Auto** | Work through the task, with the CLI's own safety checks. |

Each agent keeps its own native permission rules, and Claudex never grants more than the CLI allows.
