# Use both agents together

- Start a message with **@claude** or **@codex** to choose who answers.
- Type **#** to attach files, and **@** to attach threads or pick an agent.
- **Continue in another agent** hands a thread to the other CLI with its history.
- An agent can ask the other to take on part of a task. You approve each handoff.

Edits show up as diffs inside the thread, and the **Changes** panel shows the folder's uncommitted Git changes.
